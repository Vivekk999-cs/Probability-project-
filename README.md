# Probability-project-
Probability-Based Word Predictor 

Project Overview

This project aims to develop a word prediction system using probability theory and statistics.

The basic idea is to analyze a collection of text, calculate how frequently words occur, and use those frequencies to construct a probability distribution. 
In later stages, this probability model will be extended to consider the context of previous words and predict the next word.

The focus is on preparing the text data and building a basic probability model.
